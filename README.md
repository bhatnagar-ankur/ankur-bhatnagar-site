# Ankur Bhatnagar - Interactive Resume

An interactive, scroll-driven resume website showcasing 13+ years of experience as a Technical Architect and UI/UX Practice Head.

## 🎨 Design Philosophy

**"Blueprint meets Digital Dashboard"** - A modern, architect-themed design featuring:
- Deep navy/charcoal color scheme (#0D1117)
- Electric cyan (#00C8FF) and amber (#F0883E) accents
- Animated grid overlays and precision typography
- Sophisticated glassmorphism effects
- Smooth scroll animations and transitions

## ✨ Features

- **Animated Hero Section** with typewriter effect and floating experience badge
- **Professional Summary** with animated stat counters
- **Technical Skills** with animated skill bars and category cards
- **Interactive Timeline** for work experience (expandable cards)
- **Project Showcase** with horizontal scroll carousel
- **Achievements & Recognition** wall with awards and certifications
- **Education Section** with glassmorphism cards
- **Contact Section** with social links and email copy functionality
- **Sticky Navigation** with active section highlighting
- **Scroll-to-Top Button** for easy navigation
- **Fully Responsive** design for mobile, tablet, and desktop

## 🛠️ Technologies Used

- **React 18** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling
- **Motion (Framer Motion)** - Animations
- **Lucide React** - Icons
- **React Intersection Observer** - Scroll animations
- **Vite** - Build tool

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📦 Deploying to GitHub Pages

This React application can be easily deployed to GitHub Pages:

1. **Deploy:**
   ```bash
   npm run deploy
   ```
   This runs `predeploy` (build) then pushes `dist/` to the `gh-pages` branch, per the `homepage`/`predeploy`/`deploy` entries already in `package.json`.

2. **Configure GitHub Pages:**
   - Go to your repository settings
   - Navigate to "Pages" section
   - Select "gh-pages" branch as source
   - Your site will be live at the homepage URL
